# The web-platform-tests areas `ctest` runs, one path prefix per line.
#
# This file exists because an area with no committed expectations defaults to
# "every subtest passes", which is false for every area nobody has looked at
# yet -- so running everything would fail by the thousand and mean nothing.
#
# **It is now the whole checkout**, as of the M-B baseline of 2026-08-10: every
# one of the 21,265 testharness tests in tools/wpt/directories.txt has a
# measured expectation, so there is nothing left to hold back. What the list
# still does is name the areas explicitly rather than defaulting to "run
# everything", so that adding a directory to directories.txt does not silently
# add several thousand tests to the gate before anyone has looked at them.
#
# Reftests are in the gate as of 2026-08-31 (plan task F10) and are governed by
# this list too: `--testharness-only` is gone from the ctest registration, so a
# prefix added here adds both halves of that directory. All 20,998 reftests have
# had committed expectations since 2026-08-17 (task F9); what kept them out was
# eight that flipped between two runs of the same binary, and seven of those
# were one bug in the browser's font cache rather than anything about the suite.
# `microbrowser_wpt --reftests-only` still runs the pixel half alone, in about
# ninety seconds.
#
# Where each area actually stands is `docs/wpt-baseline.md`, which is generated
# by the run that measured it.
